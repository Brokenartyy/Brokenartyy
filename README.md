## 💎 Featured Project — Goodnight, Pretty Ripper! (MGRR fangame)

> "Every blade has a bedtime story."

**Goodnight, Pretty Ripper!** is a narrative-driven project blending psychological tension, emotional fracture, and quiet rebellion into one continuous storyline.

This project explores:
- 🩸 Moral ambiguity and consequence
- 🌙 Fragmented identity and hidden truth
- ⚖️ The thin line between justice and obsession
- 🎭 Dialogue-heavy storytelling with layered subtext

Unlike typical action-driven works, *Goodnight, Pretty Ripper!* leans into atmosphere.  
It moves slowly. Intentionally.  
Each chapter adds weight rather than noise.

### 🛠 Core Elements
- Structured long-form storytelling
- Character-focused development arcs
- Legal and ethical realism undertones
- Subtle plot twists that reframe earlier events

### 🚀 Project Status
Currently in active development. The story architecture is designed for long-term continuity and evolving narrative tension.

⭐ If you enjoy morally grey characters and slow-burn psychological storytelling, this one’s for you.
